<h1 align="center">🚀 JavaScript Practice </h1>
<h3 align="center" >A collection of real-world JavaScript problems designed to strengthen your fundamentals and improve your problem-solving skills. <h3>

# 📚 Practice Rules

- ✅ Solve every problem without watching a tutorial.
- ✅ Write clean, readable code.
- ✅ Use meaningful variable names.
- ✅ Add comments only when necessary.
- ✅ Try solving each problem in more than one way.
- ✅ Test your solution with multiple inputs.
- ✅ Refactor your code after completing each challenge.

## 📌 Objective
This practice set is designed to help you become confident with modern JavaScript by solving practical coding challenges instead of memorizing syntax.
By completing these challenges, you will gain hands-on experience with:

- Variables (`var`, `let`, `const`)
- Default Parameters
- Template Literals
- Arrow Functions
- Spread & Rest Operators
- Object & Array Destructuring
- Object Methods
- Nested Objects
- Optional Chaining
- Object Looping
- Primitive & Non-Primitive Data Types
- `null` vs `undefined`
- Truthy & Falsy Values
- `==` vs `===`
- Scope & Hoisting
- Closures
- Callback Functions
- Pass by Value & Pass by Reference
- Pre & Post Increment
- Array Methods (`map`, `forEach`, `filter`, `find`, `reduce`, `slice`)

## Tier 1 - questions
16. Student Introduction
    Create a function that accepts:

- Name
- Age
- Country
  Print a nicely formatted introduction using template literals.

17. Smart Calculator
    Create a calculator function that supports:

- Addition
- Subtraction
- Multiplication
- Division
  If the second number is missing, use a default value.

18. Clone an Array
    Given an array of fruits:

- Create a new array
- Add new fruits
- Do not modify the original array

19. Count Even Numbers
    Given an array of numbers:
    Count how many even numbers exist.

20. Number Analyzer
    Create a function that returns:

- Largest Number
- Smallest Number
- Total Numbers
- Average

21. Employee Card
    Display employee information using object destructuring.

22. Product Information
    Given a product object, generate a readable product description.

23. Object Explorer
    Print:

- All Keys
- All Values
- All Entries

24. Freeze vs Seal
    Create an object and experiment with:

- Adding properties
- Updating properties
- Deleting properties
  Compare the behavior of:
- `Object.freeze()`
- `Object.seal()`
  Write down your observations.

25. Nested User Database
    Create a nested object representing users.
    Safely access deeply nested properties.
    Loop through every user.

26. Student Result System
    Filter students who passed the exam.

27. Product Names
    Extract only the product names from an array of objects.

28. Highest Salary
    Find the employee with the highest salary.

29. Shopping Cart
    Calculate the total cart price.

30. Slice Practice
    Extract a portion of an array without modifying the original.

31. Truthy & Falsy Playground
    Test different values including:

- `0`
- `1`
- `""`
- `"Hello"`
- `null`
- `undefined`
- `NaN`
- `false`
- `[]`
- `{}`
  Determine whether each value is Truthy or Falsy.

32. Equality Checker
    Predict the output before running the code.
    Test:

- `==`
- `===`
  Explain **why** each comparison returns its result.

33. Pass by Value vs Pass by Reference
    Create examples using:

- Primitive values
- Arrays
- Objects
  Observe how changing values inside functions affects the originals.

34. Build Your Own Counter
    Create a counter using closures.
    Each function call should remember the previous value.

35. Student Management System

- Add Student
- Remove Student
- Update Student
- Find Student
- Filter Students
- Calculate Average Marks
- Display Student Details
- Clone Data

- Use Destructuring
- Use Template Literals
